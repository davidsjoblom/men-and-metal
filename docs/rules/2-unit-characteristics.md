# Unit Characteristics

All units have a number of characteristics that determine how they act on the Battlefield.
These are found in each unit's Unit Profile.

## Unit Name

All units have a unique Unit Name.

## Unit Type

Each unit has a Unit Type.
Unit Types dictates how a unit interacts with different Terrain Features.

There are 3 Unit Types:

- Infantry
- Light Motorized
- Vehicle

## Model Number

The number of models in the unit.

## Base Size

The diameter of the model's base.

## Movement Speed

A unit's Movement Speed determines how far a unit can move during an Advance, Regroup and Sprint move.

A unit has two values for Movement Speed; one when moving during an Advance and Regroup Order and one when moving during a Sprint Order. 
A unit has two values for Movement Speed; the first one is used for Advance and Regroup moves and the second is used for Sprint moves.

Movement Speed is denoted as two distance values separated by a '/', for example '4"/8" '.

## Effective Range

A unit's Effective Range is the maximum distance that the unit can effectively target and attack enemy units.

Effective Range is measured in inches.

## Soft Attack

Soft Attack is the characteristic used to determine Target Numbers for Combat Tests when targeting Infantry and Light Motorized units.

Soft Attack is split into two components; Suppression and Lethality.
Suppression is the Target Number to successfully inflict a Pin on a Combat Test and Lethality is the Target Number to successfully inflict a Casualty on a Combat Test.

Soft Attack is denoted as a pair of values separated by '/', with the first being Suppression and the second Lethality, for example '5+/6+'.

If a unit does not have a Target Number for Lethality then it is unable to inflict any casualties.

## Hard Attack

Hard attack functions identically as Soft attack but is used when targeting Vehicle units.

## Discipline

A unit's Discipline represents its ability to keep fighting under pressure and shake off suppression.
Discipline determines the Target Number for Rally and Nerve Tests.

## Keywords

Most units have one or more Keywords that categorize them and affect how they function.

## Points Cost

This is the number of Army Points a unit costs to add to an Army List.
